# LeLivreDuJour

Petit bot Mastodon sur le serveur [Piaille](piaille.fr) qui pouette automatiquement les livres de maisons indépendantes.

> [@LeLivreDuJour](https://piaille.fr/@LeLivreDuJour)

Le bot est toujours en cours de codage, de nouveaux livres et maisons indépendantes arriveront à l'avenir.

## Crédits

Inspiré du bot [LeFilmDuJour](https://piaille.fr/@LeFilmDuJour), voir son [repo](https://github.com/n1k0/LeFilmDuJour).
